> [!note]

> 正式版发布：在 rc3 基础上修复「测试点」tab 缺少保存按钮的问题。完整功能清单见 [1.0.0-rc1](./1.0.0-rc1.md)、[1.0.0-rc2](./1.0.0-rc2.md)、[1.0.0-rc3](./1.0.0-rc3.md) 更新日志。

## 🐛 修复

- **测试点 tab 增加「保存」按钮**：编辑测试数据 / 子任务后可直接保存，无需切到「高级 JSON」页

## 📦 安装

- Windows：`Tuack-GUI_1.0.0_x64-setup.exe`（需 Windows 10 1809+；精简版系统请先安装 VC++ 运行库）
- Linux：`Tuack-GUI_1.0.0_amd64.deb`
- Tuack-NG 与 Typst 已内置，无需单独安装

## ⚠️ 已知限制

- 暂不支持 macOS（Tuack-NG 尚未提供 macOS 发布二进制）
- `args`、`subtasks` 策略、`checker` 依赖等复杂字段，仍需通过「高级 JSON」手动编辑
