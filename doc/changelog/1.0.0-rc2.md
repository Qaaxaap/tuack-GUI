1.0.0-rc2

> [!note]
>
> 修复 rc1 在 Windows 上的关键缺陷：命令执行无输出、不产生任何文件。

## 🐛 修复

- **Windows：命令执行挂起**（无输出、gen 不生成文件、ren 无产物、进程不退出）——根因是 portable-pty 0.9 的 ConPTY 带 `PSEUDOCONSOLE_INHERIT_CURSOR`，子进程挂接控制台时 conhost 发送 DSR 光标查询并阻塞等待应答；现 openpty 后立即应答 `\x1b[1;1R` 并保活 stdin 写入端（参考 vercel/turborepo#11816）
- 消除 Windows 构建中 `ensure_assets` 的死代码警告（cfg 门控整段）

## 其它

- 本版本基于 rc1，其余功能与 rc1 一致，详见 [1.0.0-rc1 更新日志](https://github.com/Qaaxaap/tuack-gui/blob/main/doc/changelog/1.0.0-rc1.md)
