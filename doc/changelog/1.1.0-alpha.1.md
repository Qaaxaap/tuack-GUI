> v1.1 开发线首个预览：评测与数据体验、题面编辑与渲染预览增强（基于 v1.0.0）。

## ✨ 新增功能与优化

- **【编辑】题面 Markdown 编辑器**：CodeMirror 高亮 + Ctrl+S 保存，编辑 `statement.md`；保存后可选自动渲染（默认开，编辑器头栏开关），渲染中保存自动排队补渲染
- **【预览】配置与渲染预览并排**：选中题目/场次后右侧实时预览 ren 产物；页宽自适应 + 50%–100% 缩放（Ctrl+滚轮）+ 一键渲染；窄屏退化为「配置 / 编辑 / 预览」切换
- **【评测】args / subtasks / checker 可视化编辑**：测试点 tab 内结构化编辑（int/float/str/bool 类型选择、subtask 评分策略、checker 与 validator 的 data/sample 配置），无需手写 JSON
- **【评测】记分板历史记录**：每次评测完成后快照 `result.csv` / `result-sample.csv`，可在「评测结果」页切换查看历史场次
- **【健壮性】全局错误提示**：非良性操作失败不再静默，右下角 Toast 统一提示
- **【品牌】全套图标更新**：Tuack-GUI 新标志（深色圆角底），窗口图标随主题切换深浅变体

## 🐛 修复

- 测试点 tab 增加独立「保存」按钮，编辑后无需切到高级 JSON 页保存
- 高级 JSON / 题面编辑器：软折行 + 高度链修复（翻页失效、输入卡顿）
- 预览不随自动渲染刷新（同路径 PDF 未重读旧位图）
- 题面保存不再被运行中的命令禁用
- PDF 预览滚动条振荡闪烁、高分屏文字模糊
