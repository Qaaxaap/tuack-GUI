> [!NOTE]

> v1.1 开发线首个预览：评测与数据体验增强（基于 v1.0.0）。

## ✨ 新增

- 全局错误提示：非良性操作失败不再静默，右下角 Toast 统一提示
- 记分板历史记录：每次评测完成后快照 `result.csv` / `result-sample.csv`，可在「评测结果」页切换查看历史场次
- `args` / `subtasks` 策略 / `checker` 依赖可视化编辑：测试点 tab 内结构化编辑（int/float/str/bool 类型选择、subtask 评分策略、checker 与 validator 的 data/sample 配置），无需手写 JSON
- 测试点 tab 增加独立「保存」按钮，编辑数据后无需切到高级 JSON 页保存
