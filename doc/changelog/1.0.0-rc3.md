1.0.0-rc3

> [!NOTE]
>
> 修复 rc2 在精简版 Windows 上的 PDF 渲染崩溃，并带来平台化标题栏与命令分组。

> [!NOTE]
>
> 若无新的 bug 报告，本版本将在一天后转为正式版（v1.0.0）发布。

## ✨ 新增

- **【标题栏】平台化标题栏**：Windows/macOS 保留原生标题栏；Linux 自绘 CSD 条（最小化 / 最大化 / 关闭、整条拖拽、双击最大化），标题栏显示打开的项目名（`项目名 — Tuack-GUI`），工具栏保留品牌位
- **【命令】运行命令面板按功能分组**：分组 + 命令两级下拉（生成 / 测试 / 数据 / 渲染 / 导出 / 文档 / 配置），切换分组自动选中该组首个命令
- **【界面】工具栏 56px 主视觉 + 26px 品牌 logo**，Linux CSD 条 28px 细控制带

## 🐛 修复

- **Windows：命令执行挂起**（无输出、gen 不生成文件、ren 无产物、进程不退出）——根因是 ConPTY 初始化时的 DSR 光标查询阻塞，现已自动应答并保活 stdin 写入端（参考 vercel/turborepo#11816）
- **Windows：PDF 预览在旧 WebView2 上崩溃**（`getOrInsertComputed is not a function`）——pdf.js 改用自带 polyfill 的 legacy 构建，不再依赖内核版本（兼容裁掉 Windows Update、无法自更新 WebView2 的精简系统）
- 消除 Windows 构建中的死代码警告（不影响功能）

## 📦 安装

- Windows：`Tuack-GUI_1.0.0-rc3_x64-setup.exe`（需 Windows 10 1809+；精简版系统请先安装 VC++ 运行库）
- Linux：`Tuack-GUI_1.0.0-rc3_amd64.deb`
- Tuack-NG 与 Typst 已内置，无需单独安装

## ⚠️ 已知限制

- 暂不支持 macOS（Tuack-NG 尚未提供 macOS 发布二进制）
- `args`、`subtasks` 策略、`checker` 依赖等复杂字段，仍需通过「高级 JSON」手动编辑
