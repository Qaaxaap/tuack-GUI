0.1.0

> [!note]
>
> Tuack-GUI 首个发布版本：为 Tuack-NG 提供的跨平台图形化前端，内置 Tuack-NG 与 Typst，开箱即用。

## 🚀 新增功能

- **【界面】基于 Tauri 2 + React + TypeScript + Tailwind 的现代化暗色界面**（工具栏 / 侧栏 / 主面板 / 输出抽屉）
- **【工程】打开、新建工程；侧栏展示 contest → day → problem 三层工程树**（支持 `..` 相对路径）
- **【命令】图形化执行 Tuack-NG 命令**（`gen` / `test` / `ren` / `dmk` / `validate` / `dump` / `doc` / `conf`），输出流式展示、可取消、ANSI 彩色
- **【配置】图形化配置 conf.json**：常用字段表单 + 测试点表格编辑器（添加 / 删除 / 合并 / 拆分 / 均分 100 分）+ 高级 JSON 编辑器
- **【评测】评测记分板**：解析 `result.csv`，展示各测试点状态 / 得分 / 时间 / 空间，状态彩色区分
- **【渲染】ren 完成后自动内嵌预览 PDF**（基于 pdf.js）
- **【体验】自绘暗色目录选择器、上次工程记忆、一键在文件管理器中打开工程目录**（可配置、自动探测）
- **【分发】内置 Tuack-NG 与 Typst 二进制**，Windows 提供 NSIS 安装程序，Linux 提供 deb 包
- **【工程化】CI**（前端构建 + Rust `fmt` / `clippy` / `check`）与自动打包发布工作流

## ⚠️ 已知限制

- 暂不支持 macOS：Tuack-NG 尚未提供 macOS 发布二进制
- `args`、`subtasks` 策略、`checker` 依赖等复杂字段，仍需通过「高级 JSON」手动编辑
