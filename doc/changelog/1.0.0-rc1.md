1.0.0-rc1

> [!note]
>
> 首个候选发布：界面全面重构、终端级输出体验、工程树管理，距离正式版一步之遥。

## 🚀 新增功能

- **【主题】深色/浅色切换**：内容区、原生标题栏、窗口图标、ANSI 输出配色全联动，选择持久化
- **【图标】tuack-ng 官方标志**：工具栏 logo 随主题切换描边，窗口/任务栏/安装包图标全套
- **【终端】输出抽屉升级为 xterm.js 真终端**：进度条原地刷新、完整 ANSI 支持、可选中复制、PTY 尺寸随窗口实时同步
- **【工程树】+/- 管理**：悬浮新建场次/题目、删除题目/场次（仅从 conf.json 的 subdir 移除条目，不删磁盘文件夹）
- **【渲染】ren 模板下拉**：两级默认记忆（项目 `.tuack-gui.json` / 全局设置），工程 contest 层级新增「偏好」tab
- **【设置】设置弹窗**：tuack-ng 路径（有效性探测 + 恢复默认）、文件管理器、字体（可配置，默认 Maple Mono NF CN → JetBrains Mono）、ren 全局默认模板
- **【本地化】枚举选项中文化**：传统题/提交答案题/交互题、dmk 忽略/只生成输入/只生成输出/启用等
- **【健壮性】未检测到 tuack-ng 时拦截命令入口并弹提示**
- **【体验】文件选择器**：支持直接输入完整路径确认、大目录浏览不卡；弹窗随窗口尺寸动态调整

## 🐛 修复

- Windows 命令执行失败（assets 落点错误）与命令执行黑窗
- Linux sidecar 无执行位导致 Permission denied
- tuack-ng 默认优先自带二进制，assets 与独立安装完全隔离
- gen 成功后工程树自动刷新；gen contest 自动打开新工程
- 大量样式与交互细节（弹窗双关闭按钮、长路径截断、下拉默认项空白等）

## ⚠️ 已知限制

- 暂不支持 macOS：Tuack-NG 尚未提供 macOS 发布二进制
- `args`、`subtasks` 策略、`checker` 依赖等复杂字段，仍需通过「高级 JSON」手动编辑
