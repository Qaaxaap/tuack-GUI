> 修复 Windows / Linux 上命令无法执行的打包缺陷。

## 🐛 修复

- **修复所有命令执行失败**：`ensure_assets` 此前查找 `resource_dir()/assets`，与 `bundle.resources` 实际落点 `resource_dir()/binaries/assets/` 不一致，导致 `langs.json` 等资源从未复制到 tuack-ng 数据目录，tuack-ng 每次启动即 panic（表现为「执行命令全部不行」，而工具栏仍显示「已检测到」）
- **修复 Linux 下 sidecar 无执行位**：下载脚本写出的 tuack-ng / typst 二进制为 0644，Linux 上 spawn 报 `Permission denied`；现统一 `chmod 755`
- **恢复原生标题栏**：Windows 下可正常拖动、缩放窗口

## ✨ 界面

- 迁移至 shadcn/ui 组件体系（Button / Dialog / DropdownMenu / Tabs / Select / Checkbox），统一设计令牌
